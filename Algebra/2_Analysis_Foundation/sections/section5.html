🛑 System Collapse: The 0÷0 Trap!

At the exact instant t = 1.00s, the tracking window completely vanishes. The change in time becomes zero (Δt = 0). Algebraically, our division formula yields 0 ÷ 0, which is a critical **undefined error**. Basic algebra is fundamentally broken at a single point because a single point has zero change!

Bypassing the Wall: The Limit Definition

On Slide 1, our interval gap was calculated as b - a (or t - 1). When the gap shrunk to absolute zero, the math broke down completely because we cannot divide by zero.

To bypass this wall, mathematicians re-imagined the interval gap as a standalone tiny placeholder variable called h (where h = b - a). Therefore, instead of tracking a separate point b, we define our second point position as c + h.

This subtle notation shift is incredibly powerful: as our two points collide, we simply evaluate the limit as the spacer distance h → 0:

🧮 The Limit Definition of the Derivative: f'(c) = lim f(c + h) - f(c)h

Let's substitute our current position (c = 1) into our new path function (f(t) = t²):

f'(1) = lim (1 + h)² - (1)²h = lim 1 + 2h + h² - 1h = lim 2h + h²h = lim h(2 + h)h = lim(2 + h) = 2.00 m/s

Core Takeaway: As h → 0, the secant line transitions into a single-point **Tangent Line**. Its slope is the Instantaneous Rate of Change, or the Derivative, denoted as f'(1) = 1.00\text{ m/s}.

📉 LIMIT ENGINE: CONVERGENCE TO TANGENT

Constructing the Tangent Line Equation

The derivative value f'(c) provides the exact instantaneous slope at a single point target. To map this line across space, we anchor this slope directly into the classic algebraic **Point-Slope Formula** framework:

📐 The Canonical Point-Slope Model: y - f(c) = f'(c) · (x - c)

Where (c, f(c)) is the coordinate point and f'(c) is the slope (m).

Derivative Evaluation Masterclass

Example 4.1 (Derivative at a Point): Use the limit definition of the derivative to find the exact value of f'(3) for the quadratic function f(x) = x2.

Solution Method:
  1. Set up the limit formula: We substitute our given point c = 3 into the limit definition formula:
    f'(3) = limh→0 f(3 + h) − f(3)h
    We find our individual function values using f(x) = x2:
    f(3) = (3)2 = 9          and          f(3 + h) = (3 + h)2 = 9 + 6h + h2
  2. Expand and simplify the numerator: We substitute these expressions back into our fraction and simplify the terms on top:
    f'(3) = limh→0 (9 + 6h + h2) − 9h = limh→0 6h + h2h
  3. Simplify the fraction and evaluate the limit: Directly substituting h = 0 results in an undefined fraction (0 ⁄ 0). We take out h as a common factor in the numerator to avoid dividing by zero:
    f'(3) = limh→0 h · (6 + h)h = limh→0 (6 + h)
    Calculating the limit as h → 0 gives our final answer: f'(3) = 6 + 0 = 6.
Example 4.2 (Constructing a Tangent Equation): Find the equation of the tangent line to the curve f(x) = x2 at the point where x = 3.

Solution Method:
  1. Find the coordinates of the point and the slope: We collect the values we need at our target position c = 3:
    • The y-coordinate of the point: f(3) = 32 = 9
    • The slope of the tangent line (calculated in the previous example): f'(3) = 6
  2. Substitute the values into the formula: We substitute these values directly into the tangent line formula:
    y − 9 = 6 · (x − 3)
  3. Simplify into standard form: We expand the brackets and rearrange the equation to solve for y:
    y − 9 = 6x − 18
    y = 6x − 18 + 9      ⇒      y = 6x − 9
