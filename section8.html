Section 8 — Introduction to Functions, Domain & Range

Foundations of Functions

A function \(f\) is a mathematical rule that links each element \(x\) from a starting set, called the Domain (\(\mathcal{D}_f\)), to exactly one element \(y\) inside a final set, called the Range (\(\mathcal{R}_f\)).

Standard Function Families:
  • Linear Functions: \(f(x) = mx + p\)
    Forms a straight line. \(\mathcal{D}_f = \mathbb{R}\), \(\mathcal{R}_f = \mathbb{R}\).
  • Quadratic Functions: \(f(x) = ax^2 + bx + c\)
    Forms a parabola. Vertex occurs at: \(x_{\text{vertex}} = -\frac{b}{2a}\).
  • Reciprocal Function: \(f(x) = \frac{1}{x}\)
    Forms a hyperbola with a vertical break at \(x = 0\).

Finding Domain Constraints

When working with real numbers, you must look out for two main structural limitations that break algebraic domains:

  • 1. Fractions and Denominators: The denominator of a fraction can never be equal to zero.
    Rule: \(\frac{1}{g(x)} \implies g(x) \neq 0\)
  • 2. Square Roots: The expression inside an even square root radical must always be greater than or equal to zero.
    Rule: \(\sqrt{g(x)} \implies g(x) \geq 0\)

Demonstration Masterclass

Example 8.1: Find the domain \(\mathcal{D}_f\) for \(f(x) = \frac{\sqrt{x + 4}}{2x - 6}\).

Solution steps:
  1. Apply square root rule on numerator: \(x + 4 \geq 0 \implies x \geq -4\)
  2. Apply denominator rule on bottom: \(2x - 6 \neq 0 \implies x \neq 3\)
  3. Combine boundaries into clean intervals: \(\mathcal{D}_f = [-4, 3) \cup (3, +x)\)
Example 8.2: A quadratic function is given by the formula \(f(x) = x^2 - 6x + 5\). Find the coordinates of its vertex and determine its range \(\mathcal{R}_f\).

Solution steps:
  1. Calculate \(x_{\text{vertex}} = -\frac{b}{2a} = -\frac{-6}{2(1)} = 3\)
  2. Substitute back to find lowest \(y\)-value: \(f(3) = (3)^2 - 6(3) + 5 = -4\)
  3. Since \(a > 0\) opens up, the vertex minimum locks the range interval at: \(\mathcal{R}_f = [-4, +x)\)
