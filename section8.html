Section 8 — Introduction to Functions, Domain & Range

Foundations of Functions

A function f is a mathematical rule that links each element x from a starting set, called the Domain (Df), to exactly one element y inside a final set, called the Range (Rf).

Standard Function Families:
  • Linear Functions: f(x) = mx + p
    Forms a straight line. Domain and range include all real numbers: Df = ℝ, Rf = ℝ.
  • Quadratic Functions: f(x) = ax2 + bx + c
    Forms a symmetrical parabola. The turning point or vertex occurs at: xvertex = −b / 2a.
  • The Reciprocal Function: f(x) = 1x
    Forms a hyperbola with a horizontal break at x = 0, meaning that x cannot be zero.

Finding Domain Constraints

When a function is defined using real numbers, we find its domain by applying two main structural constraints systematically:

  • 1. Fractions and Denominators: The denominator of a fraction can never be equal to zero.
    1g(x) ⇒ g(x) ≠ 0
  • 2. Square Roots: The expression inside a square root radical layer must always be greater than or equal to zero.
    √g(x) ⇒ g(x) ≥ 0

Demonstration Masterclass

Example 8.1: Find the domain Df for the given fraction function:
f(x) = √x + 42x − 6
Solution Steps:
  1. Apply the square root constraint rule on the top numerator:
    x + 4 ≥ 0 ⇒ x ≥ −4
  2. Apply the denominator constraint rule on the bottom:
    2x − 6 ≠ 0 ⇒ 2x ≠ 6 ⇒ x ≠ 3
  3. Combine both inequalities into a single unified range:
    Df = [−4, 3) ∪ (3, +∞)
Example 8.2: A quadratic function is given by the formula f(x) = x2 − 6x + 5. Find the coordinates of its vertex and determine its range Rf.

Solution Steps:
  1. Find the x-coordinate of the vertex using the axis formula:
    xvertex = −b2a = −−62(1) = 3
  2. Substitute x = 3 back into the parent formula to find the absolute minimum height:
    f(3) = (3)2 − 6(3) + 5 = 9 − 18 + 5 = −4
  3. Because the parabola opens upwards from its lowest terminal minimum, our range interval is:
    Rf = [−4, +∞)
