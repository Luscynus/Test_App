Section 8 — Introduction to Functions, Domain & Range

Foundations of Functions

A function f is a mathematical rule that links each element x from a starting set, called the Domain (Df), to exactly one element y inside a final set, called the Range (Rf).

Standard Function Families:
  • Linear Functions: f(x) = mx + p
    Forms a straight line. Df = ℝ, Rf = ℝ.
  • Quadratic Functions: f(x) = ax2 + bx + c
    Forms a parabola. Vertex occurs at: xvertex = −b / 2a.
  • Reciprocal Function: f(x) = 1 / x
    Forms a hyperbola with a vertical break at x = 0.

Finding Domain Constraints

When working with real numbers, you must look out for two main structural limitations that break algebraic domains:

  • 1. Fractions and Denominators: The denominator of a fraction can never be equal to zero.
    Rule: 1 / g(x) ⇒ g(x) ≠ 0
  • 2. Square Roots: The expression inside an even square root radical must always be greater than or equal to zero.
    Rule: √g(x) ⇒ g(x) ≥ 0

Demonstration Masterclass

Example 8.1: Find the domain Df for f(x) = √(x + 4) / (2x − 6).

Solution steps:
  1. Apply square root rule on numerator: x + 4 ≥ 0 ⇒ x ≥ −4
  2. Apply denominator rule on bottom: 2x − 6 ≠ 0 ⇒ x ≠ 3
  3. Combine boundaries into clean intervals: Df = [−4, 3) ∪ (3, +∞)
Example 8.2: Find the vertex coordinates and range Rf for f(x) = x2 − 6x + 5.

Solution steps:
  1. Calculate xvertex = −b / 2a = −(−6) / 2(1) = 3
  2. Substitute back to get y: f(3) = (3)2 − 6(3) + 5 = 9 − 18 + 5 = −4
  3. Since a > 0 opens up, the vertex minimum locks the interval at: Rf = [−4, +∞)
